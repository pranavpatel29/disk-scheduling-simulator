# Disk Scheduling Simulator — SCAN and C-SCAN

## Project Overview
An Operating Systems SLA project that demonstrates and compares the SCAN and C-SCAN disk scheduling algorithms.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- User-defined disk size and initial head position
- Custom disk request queue
- SCAN and C-SCAN simulations
- Head movement diagrams
- Step-by-step calculations
- Performance comparison

## How to Run
1. Download `disk_scheduling_simulator.html`.
2. Open it in any modern web browser.
3. Enter the disk configuration and request queue.
4. Click **Run Both Algorithms** to view the results.
